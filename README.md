# dsh-plugins

DSH plugin market index (format 1) for plugins published by [@sss-1012](https://github.com/sss-1012).

- Index: `https://sss-1012.github.io/dsh-plugins/index.json`
- Format: 1 — validated with `@deepseek-ai/dsh-plugin-market-index`
- Plugins: `dsh-sidebar-sessions`, `dsh-harness-manager`

## Add it to DSH

Plugins → 发现 (Discover) → **添加索引源 / Add index source** → paste the URL above.

The index lists exact npm versions; DSH checks compatibility and the registry before installing, and asks for confirmation before anything is installed.
